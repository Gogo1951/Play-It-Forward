# Play It Forward

Send the gear and consumables you've outgrown to guildies or strangers who'll appreciate them. Every item is matched to the class it suits best, turning forgotten bag clutter into somebody else's next upgrade. Pay it forward, one green at a time.

**TL;DR**: For anyone with bags full of greens and leftover potions they'll never use. It finds the lowbie who needs each one and mails it to them for you.

## Features

🎁 **Makes Someone's Day** // A surprise parcel from a stranger costs you next to nothing, and it's the kind of small kindness that keeps a server worth playing on.

📬 **Ready at the Mailbox** // Open any mailbox and everything you've outgrown is already listed, so a couple of clicks sends it all on its way.

🎯 **Finds Someone Who Needs It** // Searches your guild and the leveling zones for a player a few levels shy of using each item, so nothing lands on someone who's already past it.

💛 **Generosity Tracking** // Keeps a lifetime tally of everything you've given away, and shows off the totals of other givers around town.

🦺 **Safety First** // Only sends tradeable bind-on-equip gear and spare consumables, never soulbound or quest items, and anything you'd rather keep stays put.

## Setup

1. Install the add-on, ideally using [CurseForge](https://www.curseforge.com/wow/addons/play-it-forward) or [Wago](https://addons.wago.io/addons/play-it-forward).
2. Log in and play. The defaults are ready to go, so there's nothing to set up.
3. Visit a mailbox. If you're carrying something worth passing on, the window opens by itself.
4. Press **Find Recipients**, untick anything you'd rather keep, then press **Distribute**.
5. _"It's dangerous to go alone! Take this."_

## How It Works

### The Window

| Group | What's in it |
|---|---|
| **Matched** | Someone's been picked. These are the rows Distribute sends. |
| **Pending Match** | The add-on knows who it's for, but hasn't found them yet. Press Find Recipients again. |
| **Stats Couldn't Be Read** | The game never handed over the item's stats, so it sat this round out. |
| **Kept** | Staying in your bags, because you said so or because no class wanted it. |

* Click any recipient to pick someone else, search for that one item, or keep it.
* The ticks across the top choose what's on offer: gear up to a rarity you set, plus food, drink, potions, and scrolls.

### What Lands in Their Mailbox

A parcel titled **Play It Forward!** with a short note, so a gift from a stranger never reads like a scam:

> Just a little something to help you level. (=
>
> No strings attached. Use it if you can, or sell it. Don't want it? Hit Return and it'll find a new home.

### Options

* **General** // What to give away, your generosity totals, and whether other players can see them.
* **Profiles** // Switch, copy, or reset your settings.
* **Diagnostic Tools** // Reports to attach when something isn't working.

### Slash Commands

`/pif` // Opens the Options Interface.
